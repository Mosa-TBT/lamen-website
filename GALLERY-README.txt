Gallery: open gallery.html. Edit gallery-data.js to add media.
Photos: type photo, src assets/file.jpg, title, category, source.
YouTube: type video, youtube video ID, poster assets/poster.jpg, title, category, source.
Local MP4: type video, src assets/movie.mp4, poster assets/poster.jpg, title, category.
All image files are local in assets; no Base64. YouTube films require internet and embed permission; the viewer includes an original-source link as fallback.
Achievements are in achievements.js and are shared by the home and gallery pages.
